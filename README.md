#### 🛡️ Ethical Security Testing Tool

A Python-based command-line toolkit for demonstrating common ethical hacking and network testing techniques — designed strictly for **educational** and **authorized** use only.

> ⚠️ **Legal Notice**: Use this tool only on systems you own or have explicit permission to test. Unauthorized use is illegal and unethical.

---

## 🔍 Features

- ✅ Anonymous FTP login tester
- ✅ Basic TCP listener and client (like a simple Netcat clone)
- ✅ Port scanning demo
- ✅ DNS lookup
- ✅ HTTP/banner grabbing
- ✅ WHOIS domain lookup
- ✅ OS detection & environment awareness
- ✅ Interactive command-line menu with logging
